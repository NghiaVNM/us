# 0007 — Svelte 5 + SvelteKit SPA

- Status: Accepted
- Decision: Svelte 5, SvelteKit (adapter-static, SPA), TypeScript, Vite, Paraglide i18n. Core + SQLite in a worker.
- Rejected: React (bundle size, runtime cost); SolidJS (2.0 in transition); Leptos/Dioxus (bundle size, ecosystem).
- Consequences: Static hosting; no SSR.
